## <img src="https://user-images.githubusercontent.com/74038190/216122041-518ac897-8d92-4c6b-9b3f-ca01dcaf38ee.png" width="28"/> About Me

<img align="right" width="360" src="https://user-images.githubusercontent.com/74038190/212284158-e840e285-664b-44d7-b79b-e264b5e54825.gif"/>

I'm a Computer Science and Engineering graduate of **BRAC University**, now working as a **Junior Software Engineer at Development Design Consultants Ltd.**

I learn by building systems end to end, and I work best where a research question and the engineering to answer it sit in the same project. My thesis predicted antibiotic resistance across 6,962 *E. coli* genomes and ended up saying more about how such models should be evaluated than about how they should be built. Earlier work runs the same way: an original neural architecture benchmarked against a VAE in PyTorch, an emergency-response platform nominated for the Best Project Award, and a cryptographic layer written from the primitives.

- 💼 **Junior Software Engineer** at Development Design Consultants Ltd. — Dhaka
- 🎓 **B.Sc. in CSE**, BRAC University — CGPA **3.81 / 4.00**, five consecutive merit scholarships
- 🏆 **A+** in CSE400 Project & Thesis — the highest grade awarded for the final-year research component
- 🔬 Research in **machine learning**, uncertainty modelling and model evaluation
- 🔐 I care as much about deploying and hardening a system as about designing it
- 🌐 Fluent in **Bangla** and **English**
